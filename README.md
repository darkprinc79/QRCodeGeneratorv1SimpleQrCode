# QR Code Generator

A simple Windows desktop app for turning text or a link into a QR code and saving it as a PNG or JPEG image. Your entered information is processed on your computer.

## Run

1. Install Python 3 for Windows if it is not already installed.
2. Double-click `run.bat`. On first launch it installs the QR code library, then opens the app.
3. Enter information and select **Generate QR code**. Use **Save as PNG or JPEG** to save it.
4. Enter new information and generate again as often as needed. Press **Esc** to close the app.

You can also press **Ctrl+Enter** to generate the QR code.
